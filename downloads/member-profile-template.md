# 成员科研介绍填写模板

请填写本人的真实资料，替换占位提示，并删除不适用的字段。联系方式与照片请选择可以公开展示的内容。

**提交内容、照片和后续讨论都会出现在公开的 GitHub Issue 中。** 仅提交可以公开展示的资料；提交后由网站维护者核对并更新个人页面，不会自动发布到网站。

- 网站填写说明：[提交或更新个人科研介绍](https://metaindux.github.io/team/submit/)
- 提交入口：[GitHub 成员资料表单](https://github.com/MetaIndux/MetaIndux.github.io/issues/new?template=member-profile.yml)

填写完成后，将对应内容复制到 GitHub 表单各栏目，并在表单的照片栏目上传照片。本文件供整理资料使用，不需要填写网站配置或 YAML。

## 个人照片

- 是否提供新照片：
- 照片说明或裁剪偏好（选填）：

请在 [GitHub 成员资料表单](https://github.com/MetaIndux/MetaIndux.github.io/issues/new?template=member-profile.yml)的照片栏目拖入或粘贴照片，也可使用该栏的附件上传入口。

- 使用本人照片，格式为 JPG 或 PNG，建议至少 600×600 像素、3 MB 以内。
- 建议头像清晰、头肩完整、背景简洁，并留出适合方形裁剪的空间。
- 避免多人合影、明显水印和覆盖面部的文字；暂不提供新照片时可保留现有照片或默认头像。
- 请确认照片可以公开展示。上传的原图也会出现在公开 Issue 中，不要上传含有不希望公开信息的文件。
