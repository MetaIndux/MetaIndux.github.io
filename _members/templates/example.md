# 成员资料样例与字段参考

本文件只提供格式示例，不对应真实成员。请先对照下面的可选值填写，再复制“完整成员文件样例”中的**整个代码块**到自己的 `_members/<姓名英文拼写>.md`。不要把本页说明表也复制进个人主页。

已有成员请编辑本人的原文件，保留文件名、原有 `name`、`role`、`group` 和已核实的内容。下方姓名、年份、年级、邮箱及链接都是示例，需要按本人情况替换。

## 每个字段怎么填

| 字段 | 必填或选填 | 可选值 / 填写规则 | 参考例子 |
| --- | --- | --- | --- |
| `name` | 必填 | 本人中文姓名；填写文本，不填写括号中的提示 | `张三`（仅演示姓名格式） |
| `aliases` | 必填 | 英文论文署名，使用列表；有多种本人署名可分行增加 | `San Zhang`、`S. Zhang` |
| `role` | 必填 | 常用：`phd` 博士生、`master` 硕士生、`postdoc` 博士后、`assistant-researcher` 助理研究员、`researcher` 研究员、`assistant-professor` 助理教授、`professor` 教授、`principal-investigator` 团队负责人；已有成员保留原值 | 博士生填 `phd`，硕士生填 `master` |
| `group` | 必填 | `researcher` 研究人员、`phd` 博士生、`master` 硕士生；**毕业时保留原组**，通过 `status` 标记毕业 | 博士生填 `phd`；教授、博士后通常填 `researcher` |
| `description` | 必填 | 公开展示的中文身份说明，不是代码枚举；与实际身份一致 | `博士研究生`、`硕士研究生`、`博士后`、`助理研究员`、`博士毕业生` |
| `affiliation` | 必填 | 所属学校或机构的名称，不是固定选项；已有正确值可沿用 | 北航填 `Beihang University`；其他单位填写实际名称 |
| `degree` | 学生与毕业成员填写 | `phd` 博士、`master` 硕士；教师、博士后等不适用时删除此字段 | 博士阶段填 `phd`，硕士阶段填 `master` |
| `status` | 必填 | `active` 在读或在岗；`alumni` 已毕业。按本人确认的状态填写 | 在读填 `active`；毕业填 `alumni`，将显示在团队页最下方 |
| `enrollment_year` | 学生与毕业成员必填 | 对应该博士或硕士阶段的四位数字入学年份，不加“年”、不加引号；非学生可删除 | `2023`、`2024` |
| `study_year` | 在读学生必填 | 中文写明博士／硕士几年级，由本人确认；已毕业或非学生删除此字段 | `博士一年级`、`博士三年级`、`博士四年级`、`硕士二年级`、`硕士三年级` |
| `graduation_year` | 已毕业成员必填 | 实际毕业的四位数字年份；在读或非学生删除，不填预计毕业年份 | `2025`、`2026` |
| `image` | 选填 | 已上传照片的仓库路径；没有照片可使用占位图，或删除此字段 | `/images/people/zhang-san.jpg`、`/images/people/zhang-san.png`、`/images/fallback.svg` |
| `links` | 选填 | 公开联系方式与学术链接；使用下表中的键。没有链接时填 `links: {}` | `links:` 下填写 `email`、`home-page` 等；空对象写为 `{}` |

`role`、`group`、`degree` 是不同字段，不要把“博士三年级”等中文年级写到这些字段里。当前年级写在 `study_year`。毕业时设置 `status: alumni`、填写 `graduation_year`、删除 `study_year`，保留原文件名和分组。

成员无需填写 `order`。博士生组、硕士生组及团队页最下方的毕业成员组，分别按 `enrollment_year` 从早到晚排序；同年入学按文件名排序，未填写入学年份的成员放在对应组末尾。研究人员的显示顺序由维护者管理。

## links 中可以填哪些内容

以下项目全部选填；没有的项目删除，不保留空的单项链接。

| 子字段 | 填写内容 | 参考例子 |
| --- | --- | --- |
| `email` | 愿意公开的学术邮箱，不加 `mailto:` | `yourname@buaa.edu.cn`（示例，替换为本人邮箱） |
| `home-page` | 完整个人主页网址 | `https://example.org`（示例网址，需替换） |
| `google-scholar` | Google Scholar 主页 URL 中 `user=` 后面的账号 ID，**不是完整网址** | `user=abc123AAAAAJ` 对应填 `abc123AAAAAJ`（仅格式示例） |
| `orcid` | 本人的 ORCID 编号，**不是完整网址** | `0000-0000-0000-0000`（仅格式示例，需替换） |
| `github` | 本人 GitHub 用户名，**不是完整网址** | `your-github-name`（示例，需替换） |
| `external` | 其他学术资料页的完整网址，例如本人 DBLP 页面 | 填本人学术资料的真实 `https://...` 地址 |

## 不同培养状态的修改参考

下方只是需要替换的配置片段，**不是完整成员文件**。姓名、照片、单位、正文等仍使用上面的完整结构；年份与年级必须替换为本人实际信息。

### 在读硕士

```yaml
role: master
group: master
description: 硕士研究生
degree: master
status: active
enrollment_year: 2024 # 参考年份，需替换。
study_year: 硕士三年级 # 参考年级，需由本人确认。
# 在读不填写 graduation_year。
```

### 已毕业博士

```yaml
role: phd # 保留原角色。
group: phd # 保留原分组，网站会依据 status 归入毕业成员区域。
description: 博士毕业生
degree: phd
status: alumni
enrollment_year: 2020 # 参考年份，需替换。
graduation_year: 2026 # 参考年份，需替换为实际毕业年份。
# 已毕业删除 study_year。
```

已毕业硕士的填写方式相同，将 `degree` 填为 `master`，保留原有 `role` 和 `group`，身份说明填写“硕士毕业生”。教师、研究人员等非学生保留本人原有身份配置，删除不适用的培养阶段、入学、年级及毕业年份字段。
