# 按身份复制完整成员模板

选择本人当前身份，复制对应代码块**内部的全部内容**到 `_members/<姓名英文拼写>.md`：从第一行 `---` 一直到最后的 `</div>`。不要复制标题或代码块外侧的反引号。

学生：[在读博士](#在读博士)、[在读硕士](#在读硕士)、[已毕业博士](#已毕业博士)、[已毕业硕士](#已毕业硕士)。

研究人员：[博士后](#博士后)、[助理研究员](#助理研究员)、[研究员](#研究员)、[助理教授](#助理教授)、[教授](#教授)、[团队负责人](#团队负责人)。

- **文字值**：保留模板中的英文半角双引号 `"`；把提示文字和 `【】` 一起替换掉。例如 `name: "【本人中文姓名】"` 改成 `name: "张三"`，网页不会显示引号。内容里需要引号时用中文引号“”，外侧仍保留英文半角双引号。
- **年份**：填写四位阿拉伯数字的**整数**，例如 `enrollment_year: 2023`；不加引号，不加“年”，不写月份、日期或小数。模板年份仅示范格式，必须改成本人实际年份。
- **固定字段**：所选模板中的 `role`、`group`、`status`、`degree`（如有）已经按身份填好，均为必填文字，保留双引号。这些字段不是选填项。
- **选填项**：照片和每项公开联系方式均为选填，按对应行注释操作；没有照片就保留默认头像，没有公开链接就保留 `links: {}`。不使用的联系方式注释子项整行删除，不留下占位提示或空的 `key:`。
- **缩进与注释**：同一行的字段名与值之间使用英文半角冒号，冒号后留一个空格；列表和 `links` 子项缩进两个半角空格，不用 Tab。`#` 后是填写说明，可原样保留。
- **已有成员**：编辑本人原文件，保留文件名、已有 `slug`（如有）、原有 `role`、`group` 和已核实的资料，不用模板覆盖已有完整介绍。毕业时用毕业模板中的 `status`、`description` 和培养信息更新原文件，删除 `study_year`。
- **排序**：无需填写 `order`。博士生、硕士生各组及最下方的毕业成员组，分别按入学年份从早到晚排列；同年按文件名，未填年份的暂放组末。研究人员的顺序由维护者管理。

所有 `【】`、示范年份、示范年级都要替换为已核实的本人资料。不会根据入学年份推算年级或毕业状态。照片上传与 GitHub 提交流程见 [README.md](README.md)。
