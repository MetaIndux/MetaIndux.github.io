# 在读博士完整成员文件模板

只复制下方代码块**内部的全部内容**，从第一行 `---` 到最后的 `</div>`，粘贴到本人 `_members/<姓名英文拼写>.md` 中。不要复制本页标题、说明或代码块围栏。

按每行注释填写；文字保留英文半角双引号，年份填写不加引号的四位整数。未使用的联系方式注释子项整行删除。照片上传、完整填写规范与 GitHub 提交流程见 [README.md](README.md)。
